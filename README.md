# Linux Server Administration & Troubleshooting Lab

## Scenario

This project simulates the work of a Junior Linux / DevOps Engineer
managing a Linux server for a small company.

## Company

NexaCloud

## Objective

The objective of this project is to configure and manage:

- Linux users
- Linux groups
- File and directory permissions
- Ownership
- Process management
- Troubleshooting scenarios

## Environment

- Linux: Ubuntu
- Environment: WSL
- Editor: VS Code
- Version Control: Git
- Repository: GitHub

## Project Phases

1. Requirements
2. Environment Setup
3. User & Group Management
4. Filesystem Setup
5. Access Control
6. Verification
7. Troubleshooting
8. Process Investigation
9. Documentation
10. GitHub
11. Final Review
